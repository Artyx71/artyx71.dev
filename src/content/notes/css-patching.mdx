The standard HMR loop for CSS is wasteful: the bundler detects a file change, invalidates the CSS module, re-evaluates dependencies, and re-injects a new `<style>` tag or swaps a stylesheet link. For a single property change, this is several orders of magnitude more work than necessary.

LiveStyleSync takes a different path. Instead of hooking into the module graph, it intercepts at the file level and delivers a surgical patch.

## The patch format

A patch is a minimal JSON payload:

```json
{ "selector": ".nav-link", "property": "color", "value": "#a3e635" }
```

No surrounding context. No full stylesheet. Just the diff.

## Applying the patch

The browser overlay maintains a map of injected style rules keyed by selector. When a patch arrives, it finds the relevant `CSSStyleDeclaration` and mutates it directly via `element.style.setProperty`. No DOM diffing. No re-parse.

## Keeping source in sync

The tricky part: if a full HMR reload happens afterward, the patched value gets overwritten by the file on disk. The source patcher writes the change back to the file immediately after the patch is applied, so disk and browser stay in sync.

This makes the tool useful in practice — you're not just previewing, you're committing.
